# v0.4.2 · QQ 模组分类清单

发布日期：2026-08-25

本版把 QQ 反控里的模组清单从“按 JAR 文件名罗列”升级为面向玩家的分类清单。玩家先看到服务器主玩法，再按需展开扩展关系、前置和管理组件。

## 新增功能

- 支持 !mods、!mod、!modlist 以及模组、模组列表、模组清单等中文别名。
- 按以下顺序分类：玩法内容、玩法扩展与兼容、玩家体验与信息、性能优化、服务器管理与本服定制、前置与库、其他/待识别。
- 从本地 JAR 元数据读取模组 ID、显示名、版本、必需依赖、可选依赖和运行侧。
- 对依赖玩法模组的扩展显示关联主模组；对已安装的可选联动显示已安装状态。
- 前置库支持反向显示被哪些模组使用，缺失依赖和客户端侧前置会明确标注。
- 同一个 JAR 提供多个模组 ID 时保留这些 ID 用于依赖匹配；单个 JAR 元数据损坏时仍保留文件名。

## QQ 消息体验

- 清单较短时直接发送一条普通消息。
- 清单较长时只发送一个可折叠的合并转发消息，内部按分类和长度分段。
- 合并转发不可用时退化为分段文字，仍保留完整清单，不静默截断。
- 分类顺序和子类型排序固定，玩家每次查看都能快速定位。

## 离线验证

新增 QQ 桥离线预览入口：

~~~powershell
java -cp .\tmp\javac-check QQConsoleBridge --mods-preview .\tools\ops-config.json
~~~

该入口只读取本地 mods 目录和 JAR 元数据，不连接 QQ、不调用 RCON、不写入配置。

本次发布验证包括：

- QQConsoleBridge 使用 UTF-8 独立编译通过；
- 实际 1.21.1 NeoForge 服务端样本中的所有 JAR 均生成文件项，并输出玩法、扩展、体验、性能、管理、前置和待识别分类；
- 公版精简包构建通过，生成包包含本发行说明和分类清单说明；
- 公版包不包含运行中的 mods、日志、世界、备份、配置或凭据。

## 兼容与隐私

本版不改变 Minecraft、NeoForge 或模组本身的版本要求。分类主要依赖本地元数据，遇到新模组或缺少元数据时会放入“其他/待识别”，不会伪造用途。

公版源码只包含通用分类规则和模板，不包含真实群号、QQ 账号、机器人 Token、服务器地址、日志、世界、备份或私有配置。
